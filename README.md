# Port Log - Grupo 07

## Sprint 2

### Objetivo

Aplicar conocimientos de tratamiento de imágenes y programación limpia sobre el contexto del sistema portuario para validar visualmente las infracciones.

### Introducción y contexto

Los radares ubicados en los accesos a los muelles capturan evidencia fotográfica de las infracciones de velocidad. Las cámaras toman fotografías de la proa donde se ubica la matrícula, entregando recortes ajustados ('plates') o imágenes de contexto ('completes'). Se busca determinar qué infracciones cuentan con evidencia visual válida.
